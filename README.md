# Installation
1. If not present on your computer, [download Node.js and npm](https://nodejs.org/en/download/). 
To check if they exist on your system, run `node -v` and `npm -v`, respectively.
2. Clone this repository to your computer: `git clone https://github.com/antonjolsson/AutoSFC-backend-dev.git`.
3. Make sure you are in the project root (`AutoSFC-backend-dev/`), then run `npm install`.
4. Start the application with `npm run start`. If everything works, you should see `[PM2] Process successfully started` in the process output. To see the server logs, run `npm run logs`.
